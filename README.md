# FindIt - Global Lost & Found Platform | Recovery Network

FindIt is an AI-assisted spatial matching platform that connects lost items, users, businesses, and secure verification hubs through a shared operational view.

## 🚀 Key Features
- **Hero Video & Interactive Landing Page**: Split-screen media hero with dynamic audio controls, statistics, and platform capabilities.
- **Global Authentication**: Multi-role support for **People / Individuals**, **Businesses / Organizations**, and **Secure Hubs / Desks** with real-time password strength indicators and SSO options.
- **Campus & City Spatial Radar**: Interactive location radar with active hotspot nodes, live pulsing pings, and location-based item lookups.
- **Zero-Knowledge Blind Verification**: Ownership verification challenge using hidden item markers to prevent false claims.
- **Report Wizard**: Step-by-step reporting modal for both lost and found belongings.
- **Karma & Partner Reward Hub**: Point-earning mechanics (+50 pts for reporting, +100 pts for return) redeemable for partner coupons.
- **Verified Hubs Directory**: Location guide for 24/7 security desks and safe handover dropboxes.

## 💻 Quick Start

### Prerequisites
- Node.js (v18+)

### Running Locally
```bash
# Start the local development server
npm start
# or
node server.js
```

The application will be live at:
- **Landing Page**: `http://localhost:3000`
- **Sign In / Register**: `http://localhost:3000/login`
- **Dashboard**: `http://localhost:3000/dashboard`
